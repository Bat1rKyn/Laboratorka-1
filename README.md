## Задание 1

Сформировать список из значений true и false по принципу: 
true — если очередное введенное число нечетное.
false — если очередное введённое число чётное.

## Алгоритм решения: 

1. Запуск: Программа начинается с функции main.
2. Ввод количества: Пользователь вводит число count (сколько чисел нужно проверить).
3. Создание списка: Вызывается функция checkNumbers, которая запускает цикл от 1 до count.
4. Цикл ввода: На каждой итерации программа просит ввести число.
5. Считанное число проверяется на чётность (% 2 = 0).
6. В зависимости от результата в список добавляется строка "true" (чётное) или "false" (нечётное).
7. Вывод: После завершения цикла сформированный список выводится на экран.

# Задание 2

### Текст задачи

Сформировать список из цифр числа

### Алгоритм решения

1. Попадаем в функцию main
2. Запрашиваем у пользователя число и передаем через printfn число в функцию del
3. попадаем в рекурсивную функцию дел
4. в блоке if проверяем на цифру (если у нас цифра: 1 2 3 4 5 6 7 8 9 ) то сразу записываем в список если же у нас число попадаем в блок else
5. в блоке else записываем в "значение" последнею цифру числа
6. так-же записываем в "значение" остаток числа записываем результат от рекурсивной функции дел без последней цифры
7. опять попадаем в блок if из 4 шага только число без последнего десятка
8. записываем последний десяток числа в "значение" и попадаем в шаг 6 эти действия повторяются пока не выполнится условие в блоке if из шага 4
9. после выполнения условия if из шага 4 записываем в список первую цифру числа и возвращаем список с первой цифрой
10. командой yield! добавляем его элементы из первого списка (который с первой цифрой числа) и потом командой yield добавляем последнее "значение", это выполняется пока все элементы числа не будут в одном списке
11. возвращаем список в функцию main и сразу выводим результат!
